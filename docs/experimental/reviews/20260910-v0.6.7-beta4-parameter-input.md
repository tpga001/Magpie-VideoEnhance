# Beta 4：实时参数预览和输入切换

参数面板现在独立管理关闭、编辑和预览。激活的透明输入宿主接收编辑输入和返回游戏的首击；预览继续绘制，根窗口及内容、状态等子区域退出命中检测。快捷键沿用配置中的 `EffectParameters`，默认 Alt+Shift+E，并实时更新标题栏／工具栏悬停提示。

宿主与参数输入队列均位于缩放线程。键盘、字符、鼠标和取消事件保留顺序；编辑时不再对鼠标消息优先取队而打乱修饰键顺序。记录成功呈现的当前帧窗口范围，涵盖标题栏、弹出的选项及父面板。外部游戏区域的首击由宿主完整接收，已开始的拖动在越界后仍归参数层。

焦点交接只等待控件边沿完成呈现，不等待持续到来的悬停移动。回归验证在点击松开时仍有移动消息排队，也能立即返回游戏；等待所有输入的旧条件会被该用例检出。

直接输入使用实际参数值，普通拖动保留整数步数滑条，避免把输入的小数误当作步数索引。生产控件与归一化函数的回归覆盖 0.05／0.125 的步长、小数、负值、越界及整数步长；原先直接编辑步数的路径会被 0.75 输入用例检出。

CursorManager 的编辑分支先于 3D 捕获路径，退出坐标映射并显示系统光标，避免再渲染一份软件光标。参数宿主作为内部窗口维持缩放逻辑焦点。焦点激活前和返回前均检查实际前台窗口；失焦立即取消接管，自动恢复不能覆盖其他应用。

停止与重建等待参数层本次输入的完整边沿，销毁时释放捕获、限制和宿主。原生反例确认“仅屏蔽松开”会留下 Windows 异步按键状态，因此未采用该方式。参数快捷键只在首次按下被吞掉时接管对应重复和松开，避免吞掉先前已经交付的按键释放。停止仍处于等待时，运行状态保持 Stopping。

手动应用、NR 自动重建及源窗口／模式变化保存面板状态和布局；快照采用已经请求的预览或关闭意图，不把尚在等待松开的状态错误恢复为编辑。窗口移动、尺寸和 DPI 变化继续使用已保存的逻辑位置和大小。

验证：

- `Run-ParameterInputTests.ps1`：生产输入、停止、状态恢复和快捷键片段配合真实 Dear ImGui，覆盖首次呈现命中、三态、子窗口穿透、首击、越界拖动、下拉菜单、数值输入、Esc、按键交接、切屏、焦点失败及停止等待。
- 同一脚本的布局测试：16 种视口／DPI 组合，位置与大小保存、折叠、缩小／放大和重建恢复。
- `-NativePrototype`：真实 USER32/DWM 透明显示、整窗命中、激活、解除光标限制和点击交接；以事件到达为同步条件。
- 效果组身份／名称、配置迁移及缩放前置检查回归通过；Release x64 本地验证构建通过。

这不代表实际游戏、GPU 或各补帧组合已经通过。具体兼容性矩阵见 [参数输入验收记录](../testing/PARAMETER-INPUT.md)，保留失焦暂停、降帧和后台原始输入等逐游戏待验项目。
