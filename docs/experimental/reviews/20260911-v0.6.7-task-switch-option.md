# 0.6.7 切屏自动停用开关

主页高级增加“切屏时自动停用生效效果组”，默认关闭；说明：“如果在使用 DLSSNR 时进行切屏，会让你感觉像吃了毒蘑菇，你可以尝试启用它。”旧配置缺失字段也关闭，设置自动保存并立即影响下一次事件。

沿用 0.6.6 的 Alt+Tab / Win+Tab（包括 Shift）检测以及全屏范围。开启时仅对启动中或运行中的全屏会话排队停用、挂起自动缩放和关闭倒计时，不吞系统按键，切回后等待手动启用。窗口模式不在这项附加策略范围内。关闭时在服务入口返回，不改变原有必要的窗口生命周期停止逻辑。参数面板内部焦点交接不会触发这些任务切换键。

验证通过：生产钩子／服务／运行时片段的开关、所有修饰键、空闲／启动／运行／停止状态、全屏／窗口范围、重复事件、普通按键与运行中设置变化；生产 JSON 字段读写验证新配置、旧配置、错误类型和双向重载。原有参数双路径和布局回归同时通过。未进行原生窗口或游戏输入自动化，实机兼容性待维护者体验。
