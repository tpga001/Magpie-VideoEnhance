# 0.6.7 按应用配置参数焦点切换

从主页移除“参数调整焦点切换”，移到默认配置和应用配置的常规设置。界面说明保持不变。启动使用已匹配的 Profile 值；未匹配应用沿用默认配置。运行中修改于下次启用生效，不改变当前会话的输入配对。主页高级的切屏自动停用仍为独立全局设置。

配置对象序列化独立的 parameterFocusSwitching 布尔值，移除全局写出与 UI 接口。加载旧全局值时将其作为现有配置的默认值，明确的单独配置值优先保留；存在旧全局字段时标记迁移并按现有安全保存流程写回。保存后仅剩每个配置的明确值，重载不会覆盖个别选择。新建和复制创建的配置默认关闭，即使默认配置或复制来源已开启。

验证通过：生产加载片段、JSON 布尔读取、配置写出和运行时选择赋值的回归，覆盖旧全局开启／关闭／缺失／错误值、默认及多个应用配置、已有覆盖值、互不影响的修改和重载、旧 scalingProfiles 数组、移除全局字段、新建／复制默认关闭。原有参数双路径、布局、切屏策略及其配置回归同时通过。测试不操作真实应用或用户配置。
