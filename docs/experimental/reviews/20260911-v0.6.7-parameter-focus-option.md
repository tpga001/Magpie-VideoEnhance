# 0.6.7 参数焦点切换开关

主页工具栏设置新增“参数调整焦点切换”，说明为“参数实时调整时启用焦点切换，但在部分窗口上运行时可能不稳定。”新设置默认关闭，旧配置缺失字段也保持关闭。更改立即保存，在下一次缩放会话使用；缩放运行时禁用开关，避免输入配对中途切换。

关闭时使用基于 0.6.6 的显示／关闭逻辑、鼠标消息队列和呈现命中记录。参数面板直接响应鼠标、保留标题栏关闭按钮，不创建输入宿主、不请求前台、不接管 Esc 或键盘。开启时保留完整 0.6.7 输入宿主、编辑／预览／关闭、首击直接操作、键盘数值输入及全屏生命周期保护。两条路径共用当前效果器参数、保存和重建修复。

验证：Run-ParameterInputTests.ps1 的真实 ImGui 双路径回归、16 组视口/DPI 布局、生产 JSON 读写片段的默认／旧配置／无效值／双向重载通过。Run-Beta6RegressionTests.ps1 的全屏源窗口状态与 FG FIFO 回归通过。Win32 采用确定性桩，无真实应用／游戏操作，不代表所有窗口的实机兼容性通过。

完整 Release x64 主包覆盖本地 v0.6.7-experimental，版本保持 0.6.7；同步中英发布说明和包内输入说明，可选 DLL 与 OTA 附件保留。具体构建提交、资源和文件校验记录位于分发目录。未推送、创建标签、Draft、上传或发布。
