# 0.6.7 正式分发准备

维护者要求：将 `0.6.7` 合并到开发主线，按 0.6.6 的分发结构和 Release Note 结构准备 0.6.7 文件。

## 合并与版本

- 开发主线是仓库默认分支 `experimental`。刷新 `origin` 后确认 `origin/experimental` 是 `0.6.7` 的祖先，随后将本地主线快进至 `82f8237f`，没有冲突，没有遗漏远端主线提交。
- `0.6.7` 分支保留在 Beta 6 提交；发布元数据与说明在 `experimental` 追加提交。全部 Beta 1–6 修正包含在内，保留全屏参数交接、Reflex 驱动限帧、静默回退以及不显示运行状态的要求。
- 程序和清单版本为 `0.6.7`，计划标签为 `v0.6.7-experimental`，标题为 `Magpie Experimental v0.6.7`。本地修改 `version.json` 不等于更新远端入口，当前不创建或移动标签。

本地目录为 `release/v0.6.7-experimental/`。拟分发的三个附件与 0.6.6 一致：

| `Magpie-Experimental-x64.zip` | 从干净主线提交完整构建；包内 EXE／PRI、效果与文件清单一起校验 |

## 验证与发布边界

本轮为快进合并，运行源码继承已经完成专项回归与完整构建的 `82f8237f`。发布准备的修改为元数据和文档；最终主包仍从干净提交完整重建。源码树、版本、资源、清单、ZIP、可选附件和配置保留的检查结果以分发目录中的审计记录为准。
