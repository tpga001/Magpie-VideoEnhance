# 0.6.7 Beta 2：配置目录路径修复

用户报告 Beta 1 在配置目录不存在时提示读取失败，路径包含混合的 `/` 与 `\`。

## 原因与修复

`ConfigLocations::Directory` 将多级相对路径作为含 `/` 的字符串拼接，而启动调用的 `Win32Helper::CreateDir` 仅按 `\` 分割递归创建目录；用户已有完整目录时不触发，首次安装或缺少父目录时返回 `ERROR_PATH_NOT_FOUND`（3）。

在隔离目录调用实际 `DirExists`／`CreateDir` 实现，混合路径创建失败（3），转换为 Windows 原生分隔符后成功。

配置路径改为逐级拼接并统一 `make_preferred()`，覆盖用户 v4e、便携 v4e、旧 v4、旧便携配置及备份；界面、文件读写、恢复文件和打开目录操作均沿用这些路径。配置选择顺序与原件保留规则保持一致。路径检查失败时保留原始系统错误码，供错误窗口展示。

## 验证

- 配置测试通过：新用户首次创建、已有目录、旧 v4 与备份导入、便携模式、空格与中文目录、旧混合分隔符输入。
- 目录创建测试提取当前生产函数，验证启动阶段先创建父目录的行为；此前仅用 `WriteAtomic` 创建目录的测试无法覆盖这条失败路径。
- 原有配置恢复、迁移、保存重试和缩放前置检查继续通过。
- 发布目标为 `0.6.7-beta2`；实际 UI／GPU 仍由维护者测试。
