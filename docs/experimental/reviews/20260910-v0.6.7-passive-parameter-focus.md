# 0.6.7 实时参数焦点行为回退

按维护者确认恢复被动激活：打开参数面板先显示预览，不将游戏焦点交给 Magpie；实际点击面板后由 USER32 正常激活输入宿主，首击完整接收但不修改参数，后续点击正常操作。重建后已打开面板以预览恢复，关闭请求仍保留。

移除参数宿主主动调用 SetForegroundWindow / SetFocus 的路径。缩放窗口上的预览消息不再触发宿主激活。保留编辑输入配对、越界拖动、Ctrl+单击数值输入、Esc 逐级退出、关闭时归还原游戏焦点和全屏生命周期保护。

验证：Run-ParameterInputTests.ps1 通过生产代码与真实 ImGui 输入回归及 16 组视口/DPI 布局；Run-Beta6RegressionTests.ps1 通过全屏源变化、持有输入期间待处理请求和 FG FIFO 回归。测试用 Win32 桩模拟系统点击激活，不操作真实窗口或游戏；实际游戏焦点与 GPU 验收由维护者完成。
