## 2. 已定位的问题与证据

### 2.1 弹出范围受到双重限制

`ScalingModesPage.cpp:192–194` 根据 `XamlRoot().Size()` 设置宽高，最大 820×640 DIP，并扣减主窗口边距；窗口缩小会连带压缩选择器。

`ScalingModesPage.EffectPicker.cpp:281–287` 创建普通 `Flyout`，未设置 `ShouldConstrainToRootBounds(false)`。无窗口 XAML 探针实测该 Flyout 默认值为 `true`。官方接口说明支持独立于主窗口边界的桌面弹出层，首次显示前设置即可；不能只提高 Presenter 的最大尺寸。[Microsoft：Flyout 边界属性](https://learn.microsoft.com/en-us/uwp/api/windows.ui.xaml.controls.primitives.flyoutbase.shouldconstraintorootbounds?view=winrt-26100)

### 2.2 配色绕开现有主题资源

`ScalingModesPage.EffectPicker.cpp::_UpdateEffectPickerColors` 使用固定的蓝灰背景、分隔线和青蓝选中颜色；三个不透明色块覆盖了弹出层材质。Presenter 样式也没有显式基于项目已有的 `DefaultFlyoutPresenterStyle`，需要核对并沿用现有模板。

当前工程实际使用 XAML Islands、`Windows.UI.Xaml` 和 `Microsoft.UI.Xaml 2.8.7`；`App.xaml` 已加载 WinUI 控件资源。这里按用户所指的 Magpie 主体视觉统一，无需迁移 UI 框架。`XamlWindow.h:95–99` 在支持的系统上为主窗口设置 Mica。

材质建议：主窗口沿用 Mica，选择器采用标准 Flyout 的圆角、阴影和 Acrylic（亚克力）资源。Mica 主要用于长期存在的窗口背景；弹出层采用 Acrylic 与主体属于同一套 Fluent 视觉体系。透明效果不可用时由主题提供实色回退。[Microsoft：Mica](https://learn.microsoft.com/en-us/windows/apps/design/style/mica)、[Microsoft：Acrylic 弹出层](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

### 2.3 不规则空行：隐藏条目仍累积 StackPanel 间距

已核对内置目录：155 条名称和摘要均非空，且没有换行字符。

生产实现先创建全部行，外层 `StackPanel results` 设置 `Spacing(2)`（`ScalingModesPage.EffectPicker.cpp:223–224`）；筛选时仅将未匹配行改为 `Visibility::Collapsed`（同文件第 357 行）。当前 Windows XAML 会继续为这些隐藏子元素累计 Spacing，因此不连续匹配之间出现异常空白。

已通过独立的原生 XAML 进程复现，同样使用 `StackPanel → Grid`，两条可见行各高 50 DIP，中间插入隐藏行：

| 中间隐藏条目 | Spacing | 两条可见行之间的实测间隔 |
| --- | --- | --- |
| 0 | 2 | 2 DIP |
| 1 | 2 | 4 DIP |
| 10 | 2 | 22 DIP |
| 100 | 2 | 202 DIP |
| 0／1／10／100 | 0 | 0 DIP |

这已定位一条能直接造成用户所述空行的布局缺陷。左侧分类同样使用 `StackPanel.Spacing(2)` 与隐藏子分类，需要同步修复。实际界面是否还存在其他留白问题，修复后由用户复测。

调查产物位于工作区 `.tools/effect-picker-r1-fix1/CollapsedSpacingProbe.cpp` 与 `collapsed-spacing.log`。探针没有显示窗口、启动 Magpie 或运行效果器。

### 2.4 右侧目前没有家族层级

右侧按名称排序并直接展示每个效果器。历史内容 review 已有 `family`，但生成后的产品目录只把它拼入搜索文本，`EffectPickerEntry` 没有可供分组的家族字段。

现有文件分布显示 CuNNy 20 项、CuNNy2 9 项、NNEDI3 10 项，确实容易占满列表。文件夹只用于这次数量核对，不能直接作为全部家族的分组规则，例如 `Sharpen`、`Pixel Art` 包含不同算法。
