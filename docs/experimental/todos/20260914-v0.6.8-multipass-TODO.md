## 已确认需求

- 一个 DLSSNR 效果器支持内部多层串联，总处理次数为 1～3，默认 1。
- 第二列“NR 界面修正”下方显示 `Multi Pass`，使用下拉选项 `1 / 2 / 3`；按后续调整移除“多层DLSSNR串联”说明提示。
- 不为该下拉项新增恢复默认手势或入口；用户直接选择次数。
- 从 1 改为 2 时，新增第三列 DLSSNR 参数；改为 3 时，新增第四列。
- 首次新增 Pass 2、Pass 3 时，使用当前 DLSSNR 的默认参数，不复制前一次参数。
- 2026-09-14 已确认开始执行，并部署到 Release 的 `068 local`。

## 实施方案

沿用此前方案；以下为实现约定，执行时如遇到需要改变用户可见行为的问题，再对齐。

| 总次数 | 第一列 | 第二列 | 第三列 | 第四列 |
| --- | --- | --- | --- | --- |
| 1 | Detail Control | DLSSNR · Pass 1 | 隐藏 | 隐藏 |
| 2 | Detail Control | DLSSNR · Pass 1 | DLSSNR · Pass 2 | 隐藏 |
| 3 | Detail Control | DLSSNR · Pass 1 | DLSSNR · Pass 2 | DLSSNR · Pass 3 |

- 第一列共享输入分辨率调整、Residual 系列、Shadow / Structure、Reflection / Glow 和光流选项；每个 Pass 应用相同共享设置，光流结果沿用共享服务。
- 每个 Pass 独立设置：NR Style、NR Intensity、Local Tone Strength、Local Structure Strength、Skin Structure Strength、Automatic Mask、NR UI Correction。
- Multi Pass 只出现在第二列，后续列不重复出现次数选择。
- 减少次数时隐藏并停用相应 Pass，保留其参数；再次启用时恢复此前设置。首次初始化默认值与重新启用恢复设置须区分。
- 单个参数的现有恢复默认行为只影响所属 Pass。
- 参数列向右展开；宽度不足时允许横向滚动，保持控件可读和可操作。
- 运行中的参数面板同步支持次数与各 Pass 参数。
- 处理顺序：原始画面 → Pass 1 → Pass 2（启用时）→ Pass 3（启用时）→ 下一个效果器。
- 每个 Pass 使用独立 DLSSNR 实例及时序历史；中间纹理、同步和资源释放须覆盖次数变化、尺寸变化与停止。
- 效果器列表保持一个 DLSSNR 条目，配置保存次数及各 Pass 参数；旧配置默认按 1 次运行。
- 修改次数会重建内部处理链，沿用现有自动重启机制；各 Pass 参数沿用现有即时生效或重启规则。
