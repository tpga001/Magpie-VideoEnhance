# Magpie Experimental v0.6.7 Beta 3

Includes all Beta 2 features, with the following updates:

- XeSS frame-generation names in the profiler and toolbar now omit the ZeroMV suffix.
- DLSS NR intensity, local tone strength and local structure strength now range from 0 to 2, with defaults remaining at 1.
- About links now point to the enhanced repository, with Chinese and English FAQ and contribution guides.
