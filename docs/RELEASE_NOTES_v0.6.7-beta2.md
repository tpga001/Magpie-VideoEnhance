# Magpie Experimental v0.6.7 Beta 2

Includes all Beta 1 features, with the following fixes:

- Configuration paths now use Windows backslashes (`\`), fixing startup failures when the configuration folder does not exist.
- Configuration access errors now show the system error code to help identify the problem.
